标准 OpenAI API 调用规范

可以通过 Dragon API 统一网关分发，也可以直接调用本服务的接口：

cURL 调用示例 
curl -X POST "https://api2.fanxiaolong.uk/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-YOUR_DRAGON_API_KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ],
    "stream": true
  }'
Python OpenAI SDK 调用示例 
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR_DRAGON_API_KEY",
    base_url="https://api2.fanxiaolong.uk/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello world!"}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
