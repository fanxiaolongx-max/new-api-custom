标准 OpenAI API 调用规范

在任何支持 OpenAI 格式的应用中配置即可直接调用 Grok 模型：

cURL 调用示例 
curl -X POST "https://api2.fanxiaolong.uk/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-YOUR_DRAGON_API_KEY" \
  -d '{
    "model": "grok-beta",
    "messages": [
      {"role": "user", "content": "你好，请写一首关于宇宙的十四行诗"}
    ],
    "stream": true
  }'
Python OpenAI SDK 调用示例 
from openai import OpenAI

client = OpenAI(
    api_key="sk-YOUR_DRAGON_API_KEY",
    base_url="https://api2.fanxiaolong.uk/v1"
)

response = client.chat.completions.create(
    model="grok-beta",
    messages=[{"role": "user", "content": "Hello Grok!"}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
