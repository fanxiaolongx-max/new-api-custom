① Windows 傻瓜式一键用法（零命令行！）

1. 点击右上角 「📦 下载傻瓜完整包 (.zip)」 并解压到任意文件夹。
2. 直接双击 双击启动_TaiShan运维菜单.bat：自动绕过 Windows 未签名拦截（无需手动敲 Set-ExecutionPolicy）、自动检测管理员权限与 Posh-SSH。
3. 按数字菜单选择：[1] 自动检测/装依赖 → [2] Dry-Run预演 → [3] 阶段一(改iBMC) → [4] 阶段二(配OS Bond4 · 不碰交换机) → [6] 重跑失败清单！

② 离线 / 内网机房免联网加载 Posh-SSH

脚本已内置自动优先扫描本地 .\modules\Posh-SSH：
# 有外网电脑执行一次下载离线模块包： [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12 Save-Module -Name Posh-SSH -Path .\modules # 把 .\modules 整个目录拷到本工具解压目录旁边， # 之后在完全断网的机房双击 .bat 即可秒开免安装！

③ MobaXterm 拖拽即跑（完全保留原 v10 + v16 习惯）

压缩包内同样附带两份纯 Unix LF、拖拽即跑的 MobaXterm 生产脚本与排错会话：
# 阶段一（需管理员开 MobaXterm，敲 bash + 空格 + 拖入文件回车）： bash batch_ibmc_ip.sh # 仅改管理口 Access VLAN + 出厂2.100改IP # 阶段二（前提交换机与iBMC已就绪，完全不碰交换机）： bash batch_taishan.sh # 并发SOL配双10G Bond4 + 双向Ping + LACP核验

④ 两阶段物理隔离与上线安全守则

• 阶段一 (管理网 v10)：iBMC 只有 1 个网口，管理交换机仅配 port link-type access + port default vlan，绝不下发 Eth-Trunk。
• 阶段二 (业务网 v16)：配 OS 时前提是交换机与 iBMC 已提前配好，脚本绝不登录任何交换机；严格过滤 10000Mb/s 双万兆口，内置 BOND_STAT OK(2p) 与双向 Ping 验收。
